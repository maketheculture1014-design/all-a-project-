플래너

📅 시험 D-day 학습 플랜 만들기

시험일과 과목을 넣으면, 시험일을 거꾸로 계산해 날짜별로 뭘·얼마나 공부할지 자동으로 짜줘요. 평범한 학생 기준으로 하루 분량을 무리하지 않게 나눴어요.

⏰

플랜의 3단계 원칙: 전체 기간을 ① 개념 잡기(앞 50%) → ② 기출·문제풀이(다음 30%) → ③ 모의고사·약점 복습(마지막 20%) 으로 나눠요. 시험 전날 새로운 내용 학습은 금지, 틀린 것만 다시 복습!

노트북LM노트북 만들고 마인드맵으로 전체 구조 보기

과목마다 노트북을 하나씩 만들어요. 교과서·학습지·문제집(사진·PDF·필기)을 소스(자료)로 업로드하세요.
그다음 목차를 대단원 → 소단원 → 소단원별 핵심내용 순서로 마인드맵처럼 정리하게 시킵니다.
숲을 먼저 보고 나무로 들어가는 거예요.

🧠 예시 · 중2 과학 1단원
└ 대단원: 물질의 구성
├ 소단원 1) 원소 — 핵심: 더 못 쪼개는 기본 물질, 원소기호
├ 소단원 2) 원자와 분자 — 핵심: 원자 구조, 분자식 읽기
└ 소단원 3) 이온 — 핵심: 양이온·음이온, 이온식, 앙금 반응
노트북LM · 마인드맵 프롬프트 (책 목차 기반 구조화)
너는 [과목명] 교재를 구조화하는 학습 설계 전문가야.
소스에 추가된 자료를 바탕으로 이 과목의 전체 목차를
아래 계층 구조로 빠짐없이 정리해줘.

📌 과목: [과목명]
📌 시험 유형: [예: 중간고사 / 기말고사 등]
📌 자료: [소스 참고 / 또는 목차 붙여넣기]

<구조 형식>
N대단원 [대단원 제목]
└─ N.N 중단원 [중단원 제목]
   └─ N.N.N 소단원 [소단원 제목]
      └─ 핵심 내용
</구조 형식>

<절대 규칙>
1. 목차에 숫자로 표기된 모든 항목은 생략·요약·병합 금지
   → 반드시 전부 포함할 것
2. 목차 순서를 그대로 따를 것
3. 들여쓰기로 계층 구조를 명확히 표현할 것
4. 절과 절 사이에 빈 줄 1줄 → 시각적 구분
5. 1대단원부터 마지막까지 끊지 말고 순서대로 끝까지 작성
</절대 규칙>

<핵심 내용 작성 기준>
각 소단원의 "핵심 내용"은 아래 기준으로 차등 작성:

| 개념 유형 | 작성 방식 |
|-----------|-----------|
| 평이한 개념 | 키워드 + 정의 한 줄 (암기 포인트) |
| 빈출 개념 | 키워드 + 정의 + ⭐출제 포인트 한 줄 |
| 어려운/혼동 개념 | 키워드 + 정의 + 부연 설명 (관계·맥락·혼동 포인트) |

- 출제 가능성 판단 기준: 교재 내 예상문제,
  문제집 출제 빈도가 높은 것 우선
- 비교가 필요한 개념은 "A vs B" 형태로 병기
</핵심 내용 작성 기준>
📌

왜 노트북LM? 내가 올린 자료 안에서만 답해서, 우리 학교 시험 범위에 딱 맞아요. 인터넷 아무거나 가져오지 않아요.

📱 먼저 준비 — 교과서·학습지·문제집을 'PDF'로 만들기

노트북LM에 올리려면 종이 자료를 사진이 아니라 PDF 파일로 만드는 게 좋아요. 스마트폰 무료 앱이면 1분이면 끝나요. (가장 현실적인 방법이에요!)

📋 따라 하기 (순서대로)

  1. 앱 설치 — Adobe Scan 또는 Microsoft Lens (둘 다 무료, 아이폰·안드로이드 모두 가능)
  2. 앱을 열고 카메라로 펼친 페이지를 비추기 → 종이 테두리를 자동으로 잡아줘요
  3. 촬영 버튼 한 번 → 비뚤어진 부분도 자동으로 반듯하게 보정돼요
  4. 다음 장을 계속 촬영 (여러 페이지를 하나의 PDF로 모을 수 있어요)
  5. 다 찍으면 저장(PDF) → 파일 이름은 '과목_단원'으로 (예: 과학_1단원)
  6. 그 PDF를 노트북LM에서 '소스 추가(＋)'로 업로드하면 끝!
💡

품질 좋게 + AI가 잘 읽게 하는 팁
☀️ 창가 자연광에서 찍으면 글씨가 훨씬 또렷해요 (그림자·손가락이 글자를 가리지 않게!)
📚 책 전체를 한 번에 찍지 말고 단원(중단원)별로 파일을 나누기 → 시험 범위만 골라 올리기 쉬워요
🔤 Adobe Scan은 글자 인식(OCR)까지 해줘서, 노트북LM이 PDF 속 글을 더 정확히 읽어요
🗂️ 과목별로 파일을 구분해두면, 과목별 노트북에 딱 맞게 넣을 수 있어요

🍎 아이폰 사용자는 앱 설치 없이 '메모' 앱으로도 OK

  1. 메모 앱을 열고 새 메모 만들기
  2. 아래쪽 클립(📎) 모양 아이콘 → '문서 스캔' 누르기
  3. 책의 필요한 페이지를 전부 스캔 (카메라를 대면 자동 촬영, 한 장씩 이어서 찍기)
  4. 다 찍었으면 오른쪽 아래 노란색 체크(✓) 표시 → '저장' 누르기
  5. 메모로 돌아와 위쪽 공유(↑) 화살표 아이콘 누르기
  6. 앱 목록에서 '더보기(…)' → 'Google Drive'(구글 클라우드) 선택 → 저장
  7. 구글 드라이브에 저장된 그 PDF를 노트북LM에 업로드하면 끝!
⚠️

중요 — 한 과목은 '한 번에' 모아서 PDF로!
페이지를 한 장씩 따로따로 저장하면 파일이 수십 개로 흩어져 관리가 힘들어요.
한 과목 분량을 이어서 한꺼번에 스캔한 뒤, 하나의 PDF로 정리해 저장하는 게 훨씬 좋아요.
(시험 범위가 아주 많으면 중단원별로 나눠도 OK)

🚨

아이폰 사전 세팅 (꼭 먼저 해두세요!): 메모 앱은 스캔한 사진이 사진첩에 자동 저장되도록 켜져 있을 수 있어요.
그대로 두면 스캔할 때마다 사진이 쌓여 사진첩이 금방 꽉 차요.
미리 설정 → 앱 → 메모 → 미디어 → '사진 앱에 저장' 끄기 로 꺼두면 깔끔해요.

🤖 안드로이드 사용자는 스캔 앱을 따로 받는 걸 추천

안드로이드는 기종마다 기본 기능이 달라서, 위에서 소개한 Adobe Scan이나 Microsoft Lens 같은 전용 스캔 앱을 따로 설치해서 쓰는 걸 추천해요.
(둘 다 무료이고, 자동 보정·글자 인식(OCR) 품질이 좋아요)

아니요. 핵심은 노트북LM(정리·암기·듣기) 하나만 잘 써도 큰 효과가 있어요. 사진 질문이 많으면 제미나이, 깊은 설명·글쓰기가 필요하면 클로드를 더하면 됩니다.

무료로 가능한가요?

대부분 무료 범위로 충분해요. 노트북LM은 구글 계정만 있으면 무료, 제미나이·클로드도 무료 등급이 있어요. 어려운 문제나 긴 글쓰기에서만 가끔 상위 모델이 도움이 됩니다.

시험 범위가 바뀌면요?

선생님이 정해준 범위의 자료만 노트북LM에 올리세요. 범위 밖 자료는 빼면, AI가 딱 시험 범위로만 정리·출제해줘요.

수행평가랑 출석도 올 A에 들어가나요?

네. 올 A는 시험+수행평가+출석을 모두 90점 이상으로 보는 절대평가예요. 수행평가는 클로드 첨삭으로, 출석은 가장 쉬운 점수니 절대 놓치지 마세요(지각·결석 관리).

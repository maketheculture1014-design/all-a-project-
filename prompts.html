동기부여 · 학습 코치

공부 시작이 힘들 때 — 동기부여 + 초소량 시작

의욕이 없어 시작을 못 할 때 써요. 위로 대신 "안 하면 이렇게 된다 / 하면 이만큼 남는다"는 현실 팩트로, 딱 5분짜리 미션부터 시켜서 책상에 앉게 만듭니다.

동기부여 프롬프트
너는 공부 못하는 사람을 억지로라도 책상에 앉히는 데 특화된
학습 코치야. 나는 지금 공부가 하기 싫어서 시작을 못 하고 있어.

📌 과목: [과목명]
📌 시험까지 남은 기간: [예: 3일 / 1주 등]
📌 오늘 가용 시간: [예: 2시간]
📌 지금 컨디션: [예: 피곤함 / 의욕 없음 / 불안함]

<출력 형식>
1. 현실 직시 한 줄
   - 지금 안 하면 어떻게 되는지 팩트로 한 줄

2. 5분 미션 (지금 당장)
   - 딱 5분만 하면 되는 초소량 과제 1개
   - "이것만 하고 진짜 그만둬도 됨" 수준으로

3. 5분 끝난 후 → 25분 플랜
   - 뽀모도로 1세트 (25분) 동안 할 수 있는 구체적 할 일
   - 체크리스트 형태로

4. 오늘의 최소 목표 vs 이상적 목표
   - 최소: 이것만 하면 오늘 자격 있음
   - 이상: 여기까지 하면 내일이 편해짐

5. 한 줄 응원 (감성 아닌 팩트 기반)
</출력 형식>

위로하지 말고, "안 하면 이렇게 된다 / 하면 이만큼 남는다"
식으로 현실적으로 말해줘.

소단원별 쉬운 이해

쉬운 이해 프롬프트

<출력 형식>
## [소단원명]

### 한 줄 요약

### 쉬운 설명
- 전문 용어 없이, 일상 언어로 풀어 쓰기
- 모든 전문 용어는 처음 나올 때 (쉬운 말)로 병기

### 일상 비유
- "이건 마치 ___와 같다" 형태의 비유
  (필요한 만큼 — 1개로 충분하면 1개, 여러 각도가 필요하면 추가)

### 구체적 예시
- 교과서적 예시 + 일상 예시
  (개념의 복잡도에 따라 AI가 적절한 수만큼)

### 이 개념이 시험에 나오는 방식
- 주로 어떤 형태로 출제되는지

### ⭐ 핵심 한 줄
- 시험장에서 이것만 떠올리면 되는 문장

<출력 형식>
1. 채점: __/10

   - "그러면 이건 어떻게 설명할 수 있어?" 식의 심화 확인
   - (내가 답하면 다시 채점해줘)
</출력 형식>

문제집·기출을 올리고 출제 경향을 뽑을 때 써요. 빈출 개념·헷갈리는 쌍·함정을 단원별로 정리하되, 개수를 고정하지 않고 중요도에 맞게 전부 담아줍니다.

- 출제 빈도가 높다고 판단한 근거를 간단히 표시

### ⏱️ 시간 없을 때 이것만
- 이 단원의 중요도에 비례해서 필요한 만큼 선정

<출력 규칙>

  만큼 AI가 자체 판단하여 결정

  (함정 카드 수도 고정하지 말고 필요한 만큼)
